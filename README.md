# ماسح الوثائق

تطبيق أندرويد لمسح المستندات بجودة سكنر (ماسح Google ML Kit) مع تسمية صوتية أو يدوية وحفظ PDF.

## البناء
1. ارفع هذه الملفات إلى مستودع جديد على GitHub (مع مجلد `.github`).
2. يبدأ البناء تلقائياً من تبويب **Actions**.
3. بعد انتهائه نزّل `doc-scanner-apk` من أسفل صفحة البناء، وفك الضغط وثبّت `app-debug.apk`.

## الحفظ
Documents / ماسح الوثائق / <اسم صاحب الوثائق> /
- كل مستند باسمه `.pdf`
- `جميع وثائق <الاسم>.pdf` يجمع كل الصفحات بالترتيب
